`ClipLink`是一个基于`Rust`的局域网剪贴板共享工具，用于设备之间同步文本、文件与历史记录。

## 快速构建

```bash
./scripts/build.sh windows-release
./scripts/build.sh android-release
./scripts/build.sh macos-release
```
